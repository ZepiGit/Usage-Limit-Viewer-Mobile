# Security policy

## Supported versions

Security fixes target the latest released version. Please update before checking
whether a problem still occurs.

## Report a vulnerability

[Report a vulnerability privately through GitHub](https://github.com/ZepiGit/Usage-Limit-Viewer-Mobile/security/advisories/new).
Do not post vulnerabilities or exploit details in public issues or discussions.

Include the affected app version, platform (Android or iOS), OS version, steps to
reproduce, and potential impact. Use a test account when possible.

The app handles OAuth credentials and API keys. Redact access and refresh tokens,
authorization codes, API keys, and personal account data from reports, logs, and
screenshots. A report should not require sharing real credentials.

See the [technical security model](docs/security.md) for credential storage,
authentication, and known limitations.
